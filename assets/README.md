# 参考图用途

参考资产仅提供造型、比例、姿态或材质，不提供新订单宠物的身份。图片不附带个人归属、聊天来源或本机目录信息。

| 文件 | 用途 |
|---|---|
| `template-original.jpg` | 大头小身体与留白参考 |
| `single-cat-round.png` | 猫的圆润头部轮廓 |
| `single-dog-big-head.png` | 狗的口鼻、耳形与大头造型 |
| `dog-proportion-approved.png` | 狗的头身比例参考，实际目标依订单决定 |
| `pose-dog.png` | 狗的侧坐、歪头和视线参考 |
| `pose-cat-gray.png` | 猫的侧坐、歪头和视线参考 |
| `pose-cat-golden.png` | 猫的姿态参考 |
| `duo-soft.png` | 柔软毛感与贴近布局 |
| `duo-before-softening.png` | 对照诊断毛发过锐 |

新订单宠物的面貌来自本单照片，不能复制参考动物身份。素材的公开再分发许可未核实，分享前应核对素材权限；不得加入客户原照或其个人资料。
