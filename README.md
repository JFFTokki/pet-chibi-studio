# 宠物大头萌化工作室

**Skill 名称：`pet-chibi-studio`**

把真实宠物照片变成明显大眼、圆润大头、迷你身体、柔软毛感的同款肖像，支持单宠、多宠合照和定向编辑。

## 最快开始

先安装整个文件夹，再提供本单宠物照片。在支持 `$` 技能提及的 Codex 中发送：

```text
$pet-chibi-studio
请把上传的这只猫制作成同款大头小身体肖像，输出 1 张；其余按默认标准。
```

宿主使用其他技能选择方式时，在实际选择器中选“宠物大头萌化工作室”。有生图能力就执行；只有文本能力时输出执行提示词并明确未出图。

## 仓库内容

本仓库只维护 Skill 规则、通用模板和参考资产。实际宠物照片、测试输出、订单记录和本机配置保存在仓库之外，不写入个人目录、姓名、账号、邮箱或设备信息。

## 固定提示词的使用

从 [提示词模板](references/prompt-recipes.md) 选择 N 新作、E 编辑或 C 已选作品合照，只替换字段。原照只提供身份；合照和修正保留每只用户选定作品作为参照。默认比例目标只用于新作或明确要求改比例，不能覆盖“保留这几张的比例”。重试保留完整正文和原始参照，不只用上一轮失败图。

## 常用调用

**单宠**

```text
$pet-chibi-studio
这是客户的一只金色猫，这几张都是同一只。做 1 张同款单宠图，保持它的真实眼色和鼻色。
```

**一大一小贴贴**

```text
$pet-chibi-studio
这是客户的猫和狗。做 1 张贴贴合照，狗为主，猫缩小放在画面右侧的狗前腿旁，两只靠紧，毛感柔软。
```

**只优化毛感**

```text
$pet-chibi-studio
以这张为底图，只让两只的毛更柔软蓬松，减少锐利感。
不要改变眼睛、表情、大小、头身比、位置和两只之间的距离。
```

**每只两个版本**

```text
$pet-chibi-studio
猫和狗分别各做 2 张，共 4 张独立图片。
同一只宠物的第二版只稍微改变歪头或视线，不要四宫格。
```

## 默认无需反复交代的事项

默认 1 张 1:1 单宠图；明显大眼、圆润大头、微型身体、柔软毛感、浅灰背景、完整坐姿、轻微歪头、无文字与道具。真实照片只负责“像哪只宠物”，风格图只负责“怎么画”。新客户不继承上一单的身份特征。

用户指定两只时按本单关系安排；只有明确选“一大一小贴贴”才采用对应的大小与贴近布局。数量、尺寸和背景有新指示时以新指示为准。

## 图片生成与费用边界

本包是指令型 Skill，不是独立图像模型，没有后台接单、付费 API 脚本或自动扣费功能。实际图片由所运行环境的图像工具生成；不必预设一定要 API Key。当前官方也提供原生图像工作流，但可用性应以用户客户端、权限和额度为准。

工具确实不可用时，Skill 会把本单整理成执行提示词，明确未生成图片，不假装交付。需要外部付费 API 时先取得用户授权。

## 验证边界

`stable-pet-v3` 使用固定正文与明确的参考图角色。结构检查与提示词预演不能证明出图稳定，仍需生成后按 [验收清单](references/quality-check.md) 检查。提示词与参照是软约束，不能承诺逐像素不变或每次完全一致。

## 分享与客户资料

参考资产只用于展示造型、姿态和材质；不包含个人归属或聊天来源说明。素材的公开再分发许可未核实；公开分享前应核对权限，必要时换为有权分享的示例。客户图片不自动进入公共模板或作品集。

不安装的用法见 [ChatGPT 直接使用版](CHATGPT_直接使用.md)。
