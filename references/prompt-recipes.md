# 固定提示词模板

模板版本：`stable-pet-v3`。这是提示词正文的唯一维护源；其他文档解释选择与验收，不再提供另一套比例提示词。

## 组装方式

每次提交使用 **固定任务段 + 一个模式段 + 本单物种面貌段 + 固定视觉段 + 本轮修正段（仅重试时）+ 固定负面约束**。各固定段和模式段原文复用，仅替换 `{{字段}}`；不用自由改写、同义扩写、双语重复或继续粘贴旧轮次指令。全部字段填完才提交。用户新要求覆盖模板时，只替换相应字段/条款，并记录覆盖原因。

先在订单记录冻结：模式、主体清单、图片角色、各宠物比例依据、姿态依据、相对大小、保持项、改动项。模式一轮内不变；用户提出新目标才开启新轮。策略从局部编辑切到重建也必须记录，不能偷偷换参考或目标。

### 图片角色与顺序

| 标记 | 用途 | 不能提供的内容 |
|---|---|---|
| P1…Pn | 本单真实照片，只提供对应宠物身份；同宠多照归同一 ID | 原照姿势、机位、正常身体长度 |
| A1…An | 用户指定或明确认可的本单作品；按记录提供身份、姿态、比例或材质 | 未被认可的方面不能自动升级为标准 |
| T1 / G1 | 仅姿态 / 仅比例的风格参考；同一图片可承担两者 | 示例动物的毛色、花纹与五官 |
| E1 | 用户指定的本轮编辑底图 | 不能自动覆盖 A 的保持项 |
| C1 | 本轮失败候选，只用于定位偏差或指示布局 | 不能变成下一轮唯一的身份、姿态、比例依据 |

`{{图片对应表}}` 必须写成“提交图 1 = A1 = …实际文件…，负责…”，与工具实际数组逐项一致。同一路径去重，但保留所有角色。新作顺序优先 T/G、再 P；编辑优先 E/A、再必要的 T/P、最后 C；合照优先按主体顺序放全部 A、最后 C。

合照首图与每次修正都带回每只宠物的 A；单宠修正始终带回本轮 E/A 及必要的 P/T/G。**禁止只用上一轮失败图串行重绘，也禁止只提交一句“其他不变”的修正短句。** 重发完整固定段和当前目标，修正段只写当前偏差。工具容量不足以携带必要图时，明确记录限制并停在未验证候选，不静默丢掉某只宠物的参照。

若有原照，只在身份校对确有需要时附加；已有明确指定作品的合照，不额外带原照与通用姿态图竞争。所选 A 仅在本单使用，不自动写入公共资产。

## 固定任务段（所有模式原文复用）

```text
任务：制作 {{最终数量}} 张独立的 {{画幅}} 宠物头像。本次模式：{{模式}}。
图片对应表：{{图片对应表}}
主体清单：{{主体身份与用户颜色校正}}。只呈现清单中的宠物，每只一次；同一宠物的多张参考不增加主体数量。各只的原有毛色、花纹、眼鼻色与个体特征取自其身份依据，明确的本单颜色校正优先。
保持项：{{保持项}}。
允许改动：{{允许改动}}。只实施这些改动，不重新设计已认可的部分。
表情依据：{{逐只主体的表情参考 ID 与嘴部状态}}。保留对应参考的嘴部表情，闭嘴保持闭合；张嘴时只呈现参考可见的自然舌齿，不添加人的笑容或牙齿。不同参考有冲突时采用本轮已选依据，不把张嘴和闭嘴同时要求给一只动物。
```

主体清单只填对应关系和必要辨识点；不逐项复述整张照片，不把某只宠物的具体毛色、品种或斑纹写成固定正文。表情新作取本单选定 P，编辑/合照取指定 E/A；用户指定表情覆盖该默认。

## 物种面貌段（按主体选择，接在模式段后）

仅选本单实际出现的物种，每种一次；不为单狗附猫或鸟描述。下列正文用于保留个体结构；新作的大眼、大头与圆润程度由 N 决定。E/C 未要求改脸时只作身份校对，不据此重新圆脸、放大眼睛或改耳朵。

猫：
```text
猫保留自身的鼻形、口鼻结构、耳形与耳朵自然姿态；新作突出柔和额头、饱满脸颊与小下巴，编辑与合照保留原作脸型，细胡须从口鼻两侧自然长出。不要用统一幼猫脸替代个体特征，也不添加犬类口鼻。
```

狗：
```text
狗保留自身口鼻的长度与立体厚度、鼻子形状、耳朵位置与自然姿态，以及面部毛流方向。头部造型不能靠压扁或拉长口鼻实现，也不能把狗脸改成猫脸或统一幼犬脸。
```

鸟及其他宠物：
```text
其他宠物保持其参考中实际可见、符合物种的身体结构；鸟保留自身喙形、层叠羽毛、翅膀与足趾，羽毛不变成毛发，不把所有鸟统一为弯喙，不添加猫狗耳朵或前爪。
```

## 固定视觉段（接在模式与物种段后）

```text
采用 {{画幅}} 全身构图，镜头与身体朝向服从本轮模式指定的姿态依据，保留自然的立体纵深，不增加广角畸变。将全部主体的联合轮廓居中，左右留白接近、上下留白接近，耳朵、脚和可见尾部不被画框裁断；不得为展示不可见尾部而改变已选姿势。先完成内部结构与相对大小，再等比缩放和平移整组安排留白，不拉长胸腿填满画面。背景是完全不透明的近白中性浅灰，地面与背景平滑衔接，没有明显地平线。
宽广柔光从上方和前方照向主体，在圆润形体上形成平缓的明暗过渡，接触处有浅淡、边缘柔散的阴影。氛围明亮、安静而温柔，面部和身体清楚，背景平滑且不抢眼；不增加硬边逆光或戏剧性色光。
以各宠物本身的颜色与中性背景形成对比，不任意染色或增添花纹。毛发具有柔软体积与自然交叠的毛束，短毛细密蓬松，长毛松软分层，保持各自实际毛长与质地。细毛与胡须清楚但不生硬锐化，外缘有少量柔和散开的毛丝，不做僵硬抠图边。眼睛自然嵌在脸部，保留真实眼色、瞳孔与虹膜关系、湿润反光和细小高光，不凸成玻璃弹珠；眼睛大小按本轮模式执行：N 明显放大，E/C 未要求改眼时保持选定作品大小；不为显示虹膜而改眼色。“不凸出”仅限制眼球结构与玻璃感，不抵消大眼要求。鼻子、鸟喙及可见爪部保留细微自然纹理，羽毛呈层叠羽片而非兽毛。
用商业宠物棚拍的可信材质、柔和光线与可触的柔软质地呈现本轮指定造型。写实约束用于材质与光线，不能把指定的大头小身体还原为普通成年体型；已有作品的内部比例按本轮保持项执行。
```

画幅只由 `{{画幅}}` 决定，默认 1:1；用户指定背景或光线时替换对应条款，不保留互相冲突的默认。普通合照允许必要遮挡，各只可见肢体须能分辨；“完整”指画框不裁断，不要求为了露出所有爪尾拆散合照。

## 固定负面约束（放在提示词末尾）

```text
不出现未要求的文字、水印、标志、边框、拼图、额外或重复宠物、衣饰、家具与道具。不替换个体脸部，不串用毛色花纹、眼色或耳形，不强迫张嘴，不添加人类笑容或人齿。不出现多余肢体、重复耳尾、畸形爪足、融合身体、悬空脚、凸出玻璃眼或错位瞳孔。不裁断耳脚或遮挡脸部，不出现透明底、硬阴影、过曝高光、死黑暗部、金属丝状毛发、僵硬抠图边、塑料蜡质表面、玩偶接缝、平面卡通描边、模糊面部或运动模糊。
```

负面约束也服从本轮明确要求；例如用户指定衣服时删除对应排除项。禁止普通体型、长胸长颈等比例约束只放 N 或明确改比例的 E，不用通用负面段重塑需要保留的 A。工具没有独立负面参数时将本段作为 prompt 正文，不虚构参数。

## 语言与交付

固定段使用完整自然句，组装后的视觉内容按主体与姿态、构图镜头、光线、色彩材质、风格的顺序呈现；角色映射与本轮约束保留在前面。避免堆砌 8k、masterpiece 等无可核对的质量词。

默认实际调用只用一份中文正文。用户要求英文或双语提示词时，先按同一模式填完中文，再作含义对应的英文翻译；双语展示可使用“英文完整提示词 / 中文完整提示词 / 负面约束”，实际调用只选其中一种，保存语言与实际提交内容，不把中英文叠加。不要因为外部提示词标题写了某个模型名称就修改工具或虚构该模型已可用。

## N. 从原照制作新头像

新作读取 [比例控制](proportion-control.md) 后，只选一组目标；不要把旧比例参考中的其他数字也加进去。猫狗的 `{{姿态描述}}` 固定填“后臀落地略朝画面右侧坐，左侧可见后臀，前爪靠近；头向画面左歪，左眼低右眼高，口鼻抬向右上，视线看相机附近上方，相机轻微俯拍”，用户另有要求时替换。其他动物填相应自然姿态，不强加猫狗前爪。

```text
模式 N：按身份和固定模板制作新头像。
身份仅取自 P：{{必要的可见辨识点或按对应 P 保留}}。P 中的趴卧、站立、侧脸、拍摄机位、身体长度和透视不决定本图姿势与比例。用户指定的颜色校正为 {{颜色校正或无}}；不把光线或滤镜造成的偏色当成真实毛色。
姿态取自 {{姿态参考 ID}}：{{姿态描述}}。原照不覆盖已选的姿态与机位。
比例依据：{{比例参考 ID 与单一目标}}。圆润饱满的核心头部主导外轮廓，明显宽于胸部，下巴以下的短窄躯干、小后臀、短腿和小爪组成紧凑的小底座。面部按本单物种保留个体结构，通过整体头廓形成圆润感。眼睛明显放大，大而圆、富有神情，与夸张大头和迷你身体共同构成第一眼可见的萌化特征。保留个体眼色、眼形特点和辨识度，虹膜、深色瞳孔、湿润反光与小白色高光清楚，眼球自然嵌在脸部。保留身份不等于维持原照眼睛尺寸；大眼与大头必须同时做到，不用其中一项代替另一项。优先压短颈胸、收窄躯干，前腿和脚掌短小，头下不出现长柱状胸部；不要复制原照普通成年体型，也不靠大耳朵或只放大眼睛制造大头错觉。写实仅指材质，不指普通身体比例。
风格参考只提供明确分配的姿态、比例或材质，不复制参考动物的身份。
```

## E. 已有成图的定向编辑

`{{本轮唯一目标}}` 用下方修改表中对应条目填入；只有用户同时指定两项才合并。未要求改比例时，此模式不加载新作的默认数值。

```text
模式 E：定向编辑 E1，使用 {{固定参照 ID}} 校对保持项。
本轮唯一目标：{{本轮唯一目标}}。
几何与姿态依据：{{各保持项对应的参照 ID}}。用户指定的底图优先，头脸、耳形、表情、头部侧倾、抬脸方向、视线、身体朝向与相机关系，除本轮明确允许的项目外保持。没有要求重新造型的宠物，保留其自身头身比。
{{本次具体修改}}
当前候选（如有）仅用于识别 {{具体偏差}}；目标始终相对于本轮固定参照，不按候选逐轮累乘缩放，也不把其新增偏差作为保持项。
```

| 修改类型 | 填入“本次具体修改”的固定语句，替换花括号 |
|---|---|
| 缩胸/缩身 | 保持头部大小与五官，以 E1 为基准将下巴以下身体调到 {{本轮目标身体高/宽或缩放系数}}。重点缩短真实下巴到前腿上方的胸段，并适度收窄胸宽；腿脚、后臀、落地点一起上移。不通过剪短胸毛、缩头、拉长腿颈完成。更新落地阴影，允许总高度变短，最后等比居中。 |
| 柔化/去硬边光 | 只降低 {{部位}} 的硬边高光和毛丝局部对比，保持自然毛束及原本毛长，眼鼻清楚；不改变头身比、姿势、相对大小和间距，不全图模糊。 |
| 改姿态 | 只采用 {{T 的姿态描述}}，内部头身高宽关系取自 {{A}}，不复制 T 的体型与身份。 |
| 改整只大小或距离 | 将 {{宠物 ID}} 整只等比缩放到 {{相对尺度}}，平移到 {{位置}}；其头身比、姿势、表情不变，其他宠物仅按用户要求移动，补自然接触阴影。 |
| 放大眼睛 | 仅把 {{宠物 ID}} 的眼睛调整为明显大而圆、富有神情的效果，保留原有眼色、眼形特点、视线与自然嵌入的眼球结构；头身比、嘴部表情和其他保持项不变，不画成凸出的玻璃球。 |
| 圆脸 | 只调整 {{脸颊/下颌}} 的圆润轮廓，保留个体口鼻和五官；不默认顺带缩身或放大眼睛。 |
| 找回身份 | 只依 {{P}} 修复 {{具体身份偏差}}，保留 {{A}} 的姿态、比例、布局和材质。 |

“缩小半档/一档”不是精确单位。根据本轮 E1 估计一个适度、可见的目标，简短告知解释并记录；同轮不得改变该解释，也不能把一次选定的百分比变成所有宠物的全局标准。

## C. 用已选单宠作品组合合照

支持两只及更多宠物；不因为数量增加就切回原照重新造型。**外部相对大小与内部头身比分开**：前者随布局调整，后者逐只取自 A。狗在中间、猫在左右、鸟在头顶只属于明确选择该布局的订单，不成为所有合照默认。

```text
模式 C：将 A1…An 中已经选定的宠物作品合为一张连续场景，不重新设计角色。
每只宠物的身份、表情、毛色花纹、眼鼻颜色、头部侧倾、视线、身体姿势、相机关系与内部头身比，分别取自它自己的 A。仅对整只宠物进行等比缩放和平移以完成布局；禁止单独缩头、伸长胸腿、翻转脸或用通用模板替换姿势。
本单布局：{{从观看者左右描述每只的位置、大小关系及接触关系}}。
相对大小依据：{{用户指定值，或一次选定并记录的相对尺度}}。没有明确指定的大小关系不套用上一单；不要同时下达多组相互冲突的高度和缩放百分比。
主体靠近，允许身体侧边轻触或轻微遮挡，但脸部完整，各自耳朵和肢体独立。地上宠物共享地面；若指定鸟站在另一宠物头顶，其双脚轻触头顶的毛发，允许脚趾最小限度适应接触，不站在耳尖、不悬空、不改变鸟自身比例与头部姿势。按物种形成自然接触阴影。
如果提供 C1，只借用其中 {{已通过的布局方面}}；各宠物的姿态和身体比例始终回看原始 A。发现漂移时恢复对应 A，不凭合照的失败轮廓继续自由重画。
```

若尚无单宠作品，直接以模式 N 和必要身份/模板图生成合照，在“允许改动”填一次选定的合照布局；不要无条件先多生几张单宠。混合原照与成图的订单逐只标明 N 或保留 A 的依据，不让新造型影响已有角色。

## R. 预算内修正段（视觉段后、负面约束前）

```text
本轮修正：实际候选 C1 出现 {{明确偏差}}。只恢复/修正 {{受影响的宠物与部位}}，其目标取自 {{固定参照及原目标}}。保留已通过的 {{项目}}。本段不是重新设计指令，未修改的固定段、模式目标与原始参照继续生效。
```

每轮只保留一段当前 R，不追加旧 R；每次保存实际完整提示词、按顺序提交的真实路径和输出，便于比较。提示词版本固定不等于生成式模型有确定性，仍需 [实际验收](quality-check.md)。
