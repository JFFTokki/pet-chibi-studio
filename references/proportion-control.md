# 比例控制：先确定保留还是重建

本文件是比例口径与默认数值的唯一来源。提示词模板只引用本轮选定结果，不叠加旧版本数字。文字与参考图都是软约束，不能保证精确几何。

## 两种验收依据

- **target：新作或用户明确要求改比例。** 猫狗新作的设计起点为核心头高/身体高 R = 2.2、核心头宽/躯干宽 Q = 1.8；二者是同一组高、宽目标，不是两套头高比例。视觉目标是头明显主导、身体像小底座。根据用户指定或实际物种修订时，只选一组并记录理由；同轮保持不变。鸟等非猫狗物种依相应自然解剖和选定参考估计，不硬套猫狗高宽值。
- **preserve：合照、改间距、改毛感、改姿态且明确保留比例。** 每只宠物以用户指定/认可的 A（或明确指定的 E）为比例依据。仅等比缩放整只宠物可改变外部大小；不套 R/Q 默认目标、不因粗测不足两倍而擅自再次缩身。通过代表“相对所选作品保持”，不代表达到了新作数值。
- 用户只认可姿势、同时抱怨比例时，比例仍走 target。用户说“这四张组合，姿势与身体比例保留”时，各只都走 preserve。

## 统一测量口径

猫狗只用一套口径：H = 核心头颅顶部到实际下巴，不含耳尖、零散毛丝和延伸胸毛；B = 实际下巴到脚底，包含颈、胸、腿、爪，不含阴影；W_head = 不含耳的脸颊宽；W_body = 包含可见后臀的躯干宽，不含尾巴，不能只量两前腿之间的窄条。

歪头分别记脸部轴线长度与画面纵向投影，比较前后时不得混用。模糊边界给范围，注明毛发、遮挡或透视的不确定性；不能把最低耳毛或长围脖当下巴。没有自动分割器，只能说明是人工视觉粗估。

对可测且确需改比例的底图，以固定 H/W_head 算 B_target = H/R、W_target = W_head/Q，再分别估计高度和宽度系数。原照趴卧、半身、近大远小或被衣服遮挡时只取身份，不根据它计算坐姿压缩率。用户要求“半档/一档”时先解释本轮取值，不能每次重试重新加码。

preserve 对比用无量纲 H/B、W_head/W_body、胸段占比和头脸轮廓；整只缩放不影响这些关系。先比原始 A 与成图，不能只看前一张失败 C。遮挡导致身体不可量时记 uncertain，不编造数字，也不为获取数值擅自改变布局。

## 身体调整的优先顺序

1. 头脸与姿态已合适：保持头部大小、耳形与表情，先缩短真实下巴以下到前腿上方的胸段，再按需要收窄胸、躯干和后臀。
2. 脚掌、前腿、后臀及落地点随压缩上移；不拉长腿颈填空，也不削胸毛假装结构变化。允许整体高度降低，最后调整整组留白。
3. 核对胸段和下巴至脚底总高度是否同时缩短。腿起点被毛遮挡则写不确定。指令中的百分比不是实际测得效果。
4. 比例已认可、只合照或柔化时，以上压缩步骤不执行；发现合成拉长胸部应恢复 A 的比例，而非再使用新作数值缩小一次。

## 新作与重建

使用最接近目标的 G 和 T，P 只提供身份。若一个参考同时负责比例和姿态，只提交一次并标明双角色。没有完全合格参考时说明差距，仍用现有参考和明确单一目标推进，不声称温和模板已经达到夸张目标。

同类缩身编辑没有明显效果时，下一次预算内可重建下巴以下身体；保留本轮原始 E/A 与必要 P/T/G，不让失败 C 决定新身体。用户指定底图仍保留为依据，重建的是胸腿几何而非身份或头部。胸部定向编辑已有明显改善时可以沿该方向继续，但最终目标始终相对本轮固定底图，不能逐轮叠加“再减 30%”。

## 工具与停止边界

仅在环境支持且用户选择对应方式时，才使用头身分层、缩放、蒙版或接缝重绘等更强几何控制；不要把提示词写成不存在的工具参数，不用自行写的变形脚本替代原生编辑。

按 [验收规则](quality-check.md) 执行最多 3 次出图，通过即停。预算用尽仍漂移则交付最接近的候选并写明差距。仅改 Skill 不自动生图，静态检查不等于稳定性实验。
