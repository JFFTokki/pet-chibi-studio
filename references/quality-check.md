# 实际成图验收

检查必须发生在最终回复前；工具可能先显示预览，不声称能拦截预览。文字写了要求不等于输出已经做到。检查结论按实际图像给出 passed / needs_revision / uncertain。

## 调用前防漂移检查

1. 选择 N/E/C 与各主体 target/preserve；原始固定参照真实可读，图像角色和提交顺序一致，已填完所有字段。
2. 使用固定公共段 + 一个模式段；重试附当前 R，仍发送完整正文及原始参照。没有只引用失败 C，也没有因方便丢掉某只 A。
3. 目标和本轮基准未偷偷改变，未叠加含耳/不含耳比例、多组缩放或两套姿态。旧失败图不升级为认可版。
4. “只合照/柔化/改距离”不触发默认缩身；“缩胸”允许脚底上移，不同时锁死脚底坐标。每次记录实际输入与提示词，不假设保存的文件就是已提交内容。

## 验收依据

| 任务 | 比例如何通过 | 姿态如何通过 |
|---|---|---|
| 新作 N / 本轮明确改比例 | 按本轮唯一目标检查，核心头明显主导、胸腿短窄；高宽粗测与视觉一致 | 对照 T，原照姿态未带入 |
| 编辑 E 未改比例 | 对照本轮 E/A，无明显比例漂移，不重新强制默认数值 | 除明确改动外对照 E/A |
| 合照 C | 逐只对照其 A 的内部比例，整只等比缩放后的关系保持 | 逐只核对眼睛连线、头与身体方向、视线和表情；不能只看左右站位 |

用户要求保留的作品即使不符合新作默认数值，也以 preserve 验收；如实写“保持选定作品比例”，不能宣称实现了默认两倍。反之，用户只认可姿势不能据此冻结其抱怨的长胸。

## 看图步骤

1. 缩略图检查数量、整体轮廓、主次、位置和明显大头小身体；正常尺寸比对身份、姿态；局部看毛发硬边、肢体与接触。
2. 比例统一按 [proportion-control.md](proportion-control.md) 的 H/B 和 W_head/W_body；记录图尺寸、关键点范围及误差。不把耳毛/胸毛算进头、不把前爪间距当躯干宽，不能换口径得到更好数字。
3. preserve 前后使用同一口径，按各只 A 与合照局部比较无量纲比例。遮挡或毛发边界不足时写 uncertain，不能填写假测量或“精确不变”；若只是已知布局造成不可测，先做可见部分的相对检查，不盲目缩身或换站位。
4. 缩胸另查真实胸段及下巴至脚底总高度是否一起缩短，腿脚、后臀是否上移；只削胸毛或拉长腿抵消不能通过。改善与最终达标分开记录。
5. 身份检查颜色、花纹、眼鼻喙、耳形和物种结构；蓝猫校色不能洗成白猫，真实金黄毛不能当滤镜移除。
6. 毛感检查硬轮廓光、白边和金属丝感是否压低，关键五官仍清楚；光变软不能伴随全图模糊或比例变化。
7. 合照查各只大小关系、接触、共享地面；鸟脚确实落在指定宠物头顶，不漂浮、不站耳尖，脸不被挡。
8. 确认实际宽高相等、联合轮廓居中、耳尾脚完整。对边空白平衡，四边尽量均衡；因组合宽度产生的上下留白不能靠改比例修复。

## 自动纠错与预算

默认每张最多 3 次出图（首图 + 2 次修正），通过即停，不预设每次必出两张。用户明确次数覆盖默认。输入格式错误且未生成图片可修复后重试；同一工具错误重复两次就停止，不无限循环。

- 明确失败，或关键证据不足且需要修正时，指出具体偏差，在预算内使用完整固定提示词 + 原始参照 + 当前 R；C 只定位问题。保留已通过方面。
- 合照中胸变长：恢复该宠物 A 的胸身比例；不要将失败 C 的体型作为基准再堆百分比。改留白不应顺带改身体。
- 缩身没有明显效果：按比例控制选择下巴以下重建。用户指定 E 仍作为头脸与姿态参照，不替换成漂移后的 C。
- 一次修正只处理当前错误或用户同时要求的修改；不把修复过程变成设计新表情、毛色和布局。
- 达到预算仍未通过则选最接近候选，明确残留问题，不宣称“稳定达标”。不能自动改用收费 API、绕过工具约束或无上限重试。

仅修改提示词时可以验证结构、引用和模式选择，但不宣称图像效果已改善。跨多次生成的稳定性需要实际样本比较，单张成功也不能证明确定性。
