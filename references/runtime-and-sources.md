# 运行环境、边界与官方依据

版本：1.0.0。整理日期：2026-09-20。

## 这份 Skill 是什么

这是以 `SKILL.md` 为入口的指令型工作流，带参考图、提示词模板与订单模板；没有附带独立生图服务、付费 API 脚本、后台任务或第三方登录逻辑。安装不会自行申请密钥或扣费。

Skill 规定如何看图、描述、编辑、复核；图像由宿主实际提供的生成能力完成。两者不能混为一谈。没有在用户的本地客户端验证过工具权限之前，不声称所有环境可直接出图。

## 运行顺序

1. 读取本单图片与实际可用工具说明，确认支持图片生成还是图片编辑。
2. 有原生能力时优先使用。对宿主提供的 `$imagegen` 或其他可用图像能力，遵循其当时的说明，不照抄旧聊天里的工具字段。
3. 工具允许多参考图时，标明真实照片、风格图、编辑底图的角色。蒙版工具支持时可用于限制修改范围，但不能保证生成结果逐像素不变。
4. 只有 API 能执行且用户授权时，才检查服务、权限、模型和预算；不在聊天里索要明文密钥，不把密钥写入 Skill 文件。没有配置或授权就停止该路径。
5. 仅有文本能力时，输出可执行的提示词和图片角色清单，明确“尚未生成图片”。不要用 Python 画一个近似宠物，或对整图模糊后声称完成毛发重绘。

若工具不接受 `prompt` 字段，就按宿主支持的上下文或编辑方式传递语义，不发送未定义的参数。模型、尺寸、数量、透明背景与输出格式均按真实 schema 和返回结果，不硬编码旧型号，也不从历史界面的标签推断本次模型。

## Codex 本地安装依据

官方当前文档列出个人技能目录 `$HOME/.agents/skills`、项目内 `.agents/skills`，以及 `SKILL.md` 的 `name` / `description` 元数据要求。可通过技能选择器或明确提及调用；没有显示更新时重启客户端再试。

包内 `agents/openai.yaml` 仅提供名称、描述和默认提示，没有声明不存在的 MCP 服务或生图工具依赖。

## ChatGPT 使用边界

可在普通支持生图的对话中把本包规则作为本次任务说明，配合实际上传的参考图和新宠物照片使用。这不等同于安装了一个全局自动触发的 Skill。独立 Skill 的导入与触发方式取决于实际客户端和工作区；以界面支持和官方文档为准。

不要声称“把 ZIP 拖进任意 ChatGPT 对话就会永久安装”。本包没有执行插件发布或安装操作。
