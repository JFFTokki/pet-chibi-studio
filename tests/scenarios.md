# 验收用例

这些用例供安装后进行人工或 Agent 回归测试；它们不是已经完成的图像模型测试。先测试“应采取何种行动”，再按需授权实际出图。避免一次性付费跑完所有用例。

| 输入场景 | 预期行为 | 不允许 |
|---|---|---|
| 上传同一只蓝猫 3 张照片，要求做一张同款 | 归为一个主体；1 张方形单猫图 | 生成三只猫或三张图 |
| 上传一只金色猫，要求同款 | 继承金色猫的眼鼻与花纹；只借用圆头和毛感 | 变成灰色黄眼蓝猫 |
| 上传狗，要求头身比接近模板 | 保留狗口鼻与耳形，缩身放大头 | 强制猫脸或普通幼犬比例 |
| 猫狗分别各做两张 | 4 张独立输出，同一宠物两版只轻微变姿态 | 四宫格或只给两张 |
| 只要求 1 张猫狗合照，尚无单宠作品 | 直接用两组真实身份图完成合照 | 无条件额外生成多张单宠 |
| 将猫缩小放在狗脚的右边 | 猫等比缩小并定位；狗保持 | 猫自身头身比变化 |
| 两只靠近一些 | 只缩短间距，保留相对大小 | 顺便把猫变大或换表情 |
| 太锐了，两只毛茸茸些 | 只改善毛发体积和局部光线过渡 | 全局模糊、短毛变长毛、改变距离 |
| 没有可读图片，要求编辑上一张 | 要求提供或指定实际图片 | 根据失效 ID 假装编辑 |
| 用户只要提示词 | 交付完整可用提示词，不调用生图 | 擅自消耗生成额度 |
| 当前环境只有文本工具 | 交付本单图像角色与完整提示词，标明未出图 | 假图、虚构文件、声称已生成 |
| 新客户第二单接续第一单 | 重置身份与底图，只继承通用风格 | 串用上单照片或宠物特征 |
| 用户说只改毛，其他像素不能变 | 使用支持的局部/图层能力，解释生成式编辑边界 | 保证未经验证的逐像素不变 |
| 本轮已生成 3 次仍不通过 | 保留版本并报告具体问题 | 无限重试或默默切换收费 API |

## 安装后的首轮试跑

先选择一单宠物的清晰正脸或三分之二侧脸，附 1 张本包比例示例，让 Skill 生成 1 张。检查是否仍像这只宠物、头身比是否到位、毛感是否柔软。随后只测试“毛感更软、其他保持”，比较是否发生身份或构图漂移。

同一 Skill 在不同模型、图像工具和客户端中的效果需要分别验证，不因为某一次出图成功就声称全面稳定。
